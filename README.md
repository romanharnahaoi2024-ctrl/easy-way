# Easy Way

Навчальна вебплатформа моніторингу міського пасажирського транспорту
та керованого обміну даними про розклади й GPS-позиції.

## Структура

- `backend/` — сервер FastAPI.
- `frontend/` — клієнт React і TypeScript (Vite).
- `docs/` — архітектура, вимоги та діаграми.
- `compose.yaml` — локальне середовище розробки.

## Робота з Git

1. Створи гілку від `main`, наприклад `feature/ezw-38-backend-setup`.
2. Відкрий pull request у `main`, зазнач номер задачі Jira та спосіб перевірки.
3. Перед злиттям отримай схвалення іншого учасника команди.
4. Додай посилання на PR у картку Jira та переведи її в Review.
   Перевіряльник переводить картку в Done після прийняття.

## Локальний запуск

1. Скопіюй `.env.example` у `.env` і задай пароль локальної БД.
2. Перевір конфігурацію: `docker compose config -q`.
3. Лише БД: `docker compose up -d db`.
4. Усе разом: `docker compose up --build -d`.

Інтерфейс: http://localhost:5173, перевірка стану API: http://localhost:8000/health.
