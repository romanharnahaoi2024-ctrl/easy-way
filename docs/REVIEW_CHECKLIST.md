# Чекліст рев'ю pull request (EZW-60) і приймання реалізації (EZW-65)

## Для кожного PR
- [ ] Міграції відповідають ER-моделі; чиста БД оновлюється міграціями без ручних таблиць
- [ ] API й клієнт: формати запиту, відповіді й помилок збігаються з домовленістю
- [ ] Право і згода перевіряються на сервері до видачі набору; відкликання блокує наступний запит
- [ ] Дозволений, заборонений і невалідний сценарії мають код API, статус і запис аудиту
- [ ] Паролі зі змінних середовища; міграції та запуск задокументовані
Результат у PR: що перевірено, посилання на зміну/тест/журнал.
