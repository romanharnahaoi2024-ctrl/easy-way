# Сценарій демонстрації (EZW-66)

Попередньо: `cp .env.example .env`, задати POSTGRES_PASSWORD, `docker compose up --build -d`,
застосувати міграції, завантажити `demo_data.json`, перевірити http://localhost:8000/health.

| Етап | Дії | Очікуваний результат |
|---|---|---|
| Моніторинг | Відкрити маршрут M1, показати 3 зупинки і останню GPS-позицію BUS-01 | Мапа з маршрутом і транспортом, час позиції збігається з даними |
| Дозвіл | Увійти як demo-allowed, запитати набір gps-demo | 200, дані видано, є request_id і запис аудиту |
| Відмова | Увійти як demo-no-consent, той самий запит | 403, координати не видано, причина в журналі |
| Якість | Подати набір із lat=95 | 422, запис про помилку валідації в журналі |

Зберегти скріншоти мапи, відповіді 200 і відмови 403. Записати SHA коміту та вивід `docker compose ps`.
